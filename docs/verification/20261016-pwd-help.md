- 核对 `D:/projects/vulcan-luaskills/docs/skill-development.md` 的顶层 PWD 约定，以及 `src/runtime/engine.rs` 的参数规范化边界：宿主有项目上下文时负责隐藏、注入 PWD，技能声明普通可选参数并接收注入后的值。

## 变更范围

- 顶层 PWD 改为可选；有 PWD 接受逻辑节点、`.omm/节点` 及完整路径；省略或空 PWD 时，所有显式文件操作路径必须完整。纯 before/after 文本 diff 不访问文件系统。
- 统一路径解析，明确工作区根与节点用途；不使用环境变量或进程 cwd 推断项目。项目不能位于 `.omm` 内，同批写入不能跨工作区。
- 支持 Windows 盘符、UNC、无歧义长路径前缀及相对节点反斜杠；拒绝设备命名空间、驱动器相对路径、穿越、大小写别名和链接逃逸。
- 文件操作返回 workspace，tree/read/write 返回 absolute_path，方便无 PWD 的后续调用直接复用。
- 导出仍限定所选项目 `.omm-export`；省略 output 使用固定默认文件，未传 PWD 时显式 output 必须完整。
- 保持单工具、九种 action；帮助分为总览、路径、浏览、编辑、分析、导出、工作流、错误八个主题，并注册主目录。
- 修复 tree 将 `api` 误判为 `ap` 子节点的问题，补充直接与间接后代回归。

新增正式文件：node/paths.mjs、七个分类帮助文件。新增开发文件：tests/paths.test.mjs、examples/absolute.args.json、本文。修改清单、存储与分发、Lua 注释、README、已有帮助、调用验收脚本和调试指引；未修改上游示例内容或外部项目。
