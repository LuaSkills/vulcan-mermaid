日期：2026-10-16。项目：vulcan-mermaid，版本：0.1.0。

本文记录首次本地实现的历史快照。后续 PWD、完整路径与分类帮助变更，以及当前安装包校验和，以 [后续验收记录](20261016-pwd-help.md) 为准；下列 24 文件安装包与旧摘要不再代表当前产物。

## 实现范围

- 在 vulcan-codekit 的同级目录建立独立 Git 仓库，使用 demo-skill 的开发指引、官方调试器、校验、打包与发布脚本作为基础。
- 对外仅一个规范工具名 vulcan-mermaid-workspace；宿主内部入口名 workspace，由 action 承载初始化、树、读取、批量写入、删除、校验、差异、引用、导出九种操作。
- 保留上游 .omm 磁盘版本 0.1.0、七种字段、直接嵌套目录和 YAML 元数据。导入原项目完整示例：62 个节点、6 张图；原项目和 CodeKit 工作区未修改。
- 导出自包含 HTML：内嵌数据、解析、Dagre 布局和界面代码；无 CDN、远程字体、网络请求、后台服务或云端账号流程。
- 流程图语法边界、批次非跨文件事务、只读快照、限额和错误格式已写入中英文说明。
